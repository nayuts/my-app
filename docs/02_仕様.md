# 仕様

優先度：**高**＝一段落までに必要 ／ **低**＝後回し

一段落とは、一番の困りごと（パターンでの一括完了）が解決し、アプリとして一通り動く区切りのこと。すべての機能がそろっている必要はない。

---

## 機能1：家のアカウント【高】

**ユーザーストーリー**  
同居人として、家事の記録を二人で共有したい。
なぜなら、やった家事をお互いに画面で確認できれば、口頭で報告する必要がなくなるから。

**受け入れ条件**
- [ ] 家の名前とログインの情報を決めて、家のアカウントを新規登録できる。アカウントは、二人で1つを共有する
- [ ] 新規登録のときに、二人のプロフィール（ニックネーム）も作る
- [ ] 二人は、それぞれ自分のスマホで、同じログインの情報でログインできる
- [ ] 一度ログインすれば、アプリを開くたびにログインしなくてよい
- [ ] 二人は、同じ画面（家事の記録）を見られる
- [ ] 相手が記録した内容は、画面を読み込み直したときに反映される
- [ ] アカウントの詳細で、家の名前と、二人のプロフィールを確認できる
- [ ] アカウントの詳細から、ログアウトできる

**一段落の後に作るもの【低】**
- [ ] 家の名前を編集できる

**この形にした理由**
最初は、一人ずつアカウントを作り、グループを作って合言葉で参加する形だった。二人で使うことに絞ったので、規模を抑えるために、家で1つのアカウントを共有する形にした。グループの作成・参加の画面、合言葉、二人までの上限のチェックが要らなくなる。パスワードを二人で共有し、相手のプロフィールで記録することもできてしまうが、それは「権限の制限はしない、二人の信頼関係に任せる」という判断と同じ考え方で受け入れる。

**④設計で決めること**
ログインの方法（メールアドレスかユーザーIDか、パスワードかパスキーか）。比べた内容は開発記録に残している。

## 機能2：プロフィール【高】

**ユーザーストーリー**  
同居している二人のそれぞれとして、自分のやった家事を自分のプロフィールで記録したい。
なぜなら、どちらがやったか分かるようにして論争を防ぎ、ポイントを人ごとに貯めて使えるようにするため。

**受け入れ条件**
- [ ] ログインした後、そのスマホで初めて使うときに、二人のどちらのプロフィールかを選ぶ
- [ ] 選んだプロフィールはスマホに覚えさせておき、次にアプリを開いたときは選ばなくてよい
- [ ] ログアウトすると、プロフィールの選択も消え、次にログインしたときに選び直す
- [ ] 家事の完了やポイントは、そのとき選んでいるプロフィールの記録になる
- [ ] アカウントの詳細から、プロフィールのニックネームを変えられる
- [ ] アイコンは、ニックネームの頭文字と、決まった色で表示される。色はプロフィールを作った順で決まる（例：1つ目は青、2つ目はオレンジ）ので、二人の色は必ず違う
- [ ] 家事の完了記録やポイントの使用記録には、やった人のニックネームが表示される

## 機能3：家事の追加・編集・削除【高】

**ユーザーストーリー**  
同居人として、大まかに決まっている担当の家事や細かい家事を、それぞれが登録し、家事ごとのポイントを決めておきたい。
なぜなら、登録した家事が、毎日の記録やパターン作成のもとになるから。

**受け入れ条件**
- [ ] 家事名とポイントを決めて、家事を追加できる
- [ ] ポイントは、バー（10〜200）で決めるか、数字を押して直接入力できる
- [ ] 直接入力では、0〜999の数字だけを入れられる（マイナスや小数は入らない。4桁目は打てない）
- [ ] ポイントの数字は、大きさで色が変わる（0〜49：水色、50〜99：黄緑、100〜149：オレンジ、150以上：赤）。家事の一覧、パターン、家事追加・編集画面など、ポイントを出すところでは同じ色にする（大変な家事かどうかが、ひと目で分かるようにするため。数字も一緒に出すので、色だけに頼らない）
- [ ] 家事を追加するときは、「保存して、続けて追加」で、画面を閉じずに次の家事を続けて追加できる。「保存して閉じる」で各種選択画面に戻る（最初に40個前後の家事を登録するときの手間を減らすため）
- [ ] 追加した家事を、編集・削除できる
- [ ] 家事は家のアカウントのもので、どちらが登録した家事でも、二人とも完了にできる
- [ ] 家事を編集・削除しても、過去の完了記録とポイントは、そのときの内容のまま残る

**一段落の後に作るもの【低】**
- [ ] 同じ名前の家事は登録できない。登録しようとすると「同じ名前の家事がすでにあります」と出す（同じ名前だと、パターンやホーム画面で区別できないため）
- [ ] 家事カテゴリ（掃除、料理など）を付けて、カテゴリごとに家事を見られるようにする。カテゴリのイラストも出す

一段落では、同じ名前のチェックは作らない。カテゴリも作らず、代わりに各種選択画面の検索で探せるようにする（カテゴリはテーブル・登録・切り替え・アイコン・イラストなど作るものが多いが、検索は画面だけで作れて軽いため）。同じ名前のチェックを作らないのは、チェックとエラー表示とテストの分だけ作るものが増えるためで、まずは削れるところを削る。二人で使うので、名前の付け方で避けられる。

## 機能4：パターンの作成・編集・削除【高】

**ユーザーストーリー**  
同居人として、平日・休日など、日によって違う家事の組み合わせをパターンとして登録しておきたい。
なぜなら、パターンを選ぶだけで、その日の家事をまとめて完了できるようにしたいから。

**受け入れ条件**
- [ ] パターン名を決めて、パターンを作成できる
- [ ] 登録した家事を、パターンに入れられる
- [ ] 同じ家事をパターンに2回入れると、その家事は1日に2回やるものになる（入れた数が、1日の回数になる）。数字を入力しないので、0回やとても大きな回数のような、おかしな値が入らない
- [ ] パターンを編集して、名前・入っている家事（追加・取り外し）を変えられる。回数を減らすときは、同じ家事を1つ取り外す
- [ ] パターンを削除できる
- [ ] 今選んでいるパターンを削除すると、メイン画面に「パターンを選んでください」と表示される
- [ ] パターンに入っている家事を削除すると、その家事はパターンからも消える（過去の完了記録とポイントは残る）

---

## 機能5：各種選択【高】

**ユーザーストーリー**  
同居人として、やった家事を1つずつ記録したい。
なぜなら、
- 二人で記録のタイミングが違う（同居人は夜にまとめて、自分はやるたびに記録する）から
- パターンに入らない、その日だけの単発の家事もあるから

**受け入れ条件**
- [ ] ホーム画面の右下に固定された虫眼鏡のボタンを押すと、家事の一覧が開く
- [ ] 家事は名前の順に並ぶ
- [ ] 一覧の上の検索欄に文字を打つと、その文字を含む家事だけに絞り込まれる（家事が40個前後あり、名前の順だけでは探すのが大変なため）
- [ ] 各家事に、前回完了した日（2日前、1か月前など）が表示される（しばらくやっていない家事に気づけるようにするため）
- [ ] 家事の行を押すと、そのまま完了になり、完了画面が出る
- [ ] 家事は、今日の日付で記録される
- [ ] 日付は朝5時に切り替わる（5時より前の記録は、前の日の記録になる）
- [ ] ポイントは、そのとき選んでいるプロフィール（完了ボタンを押した人）に入る
- [ ] 完了した家事には線が引かれてグレーになる。相手の画面には、読み込み直したときに反映される
- [ ] 完了した家事は、家事の一覧の一番下に移動する
- [ ] 完了した家事には、完了した人のアイコンが表示される

**一段落の後に作るもの【低】**
- [ ] どの日にやったかを、1週間前まで選べる。明日以降の日付は選べない（昨日やり忘れた家事を記録するため）

## 機能6：パターンで一括完了【高】

**ユーザーストーリー**  
同居人として、平日・休日など日によって違う家事の組み合わせを、パターンとしてまとめて完了したい。
なぜなら、今は毎日の記録に6タップ以上かかっていて、そのタップ数を減らしたいから。

**受け入れ条件**
- [ ] パターンは、一度に1つだけ選べる
- [ ] 選んだパターンは、別のパターンを選ぶまでそのまま残る
- [ ] 選んでいるパターンは二人で共通で、どちらかが変えると、相手の画面も読み込み直したときに変わる
- [ ] パターンを選ぶと、そのパターンの家事が、全部チェックされた状態でメイン画面に表示される
- [ ] やらなかった家事は、チェックを外せる
- [ ] 一括完了ボタンを1回押すと、チェックが付いている家事がすべて完了になる
- [ ] パターンどおりの日は、アプリを開いてから完了画面が出るまで、4タップ以内で一括完了できる
- [ ] やらなかった家事がある日は、チェックを外した数だけタップが増える
- [ ] 一括完了は、今日の日付で記録される（昨日の分をまとめて記録することはめったに無いため、後で1つずつの記録に日付を選べるようにしても、一括完了では選べないままにする）
- [ ] 1日に複数回やる家事は、1つの家事として表示され、終わった回数が「0/2」「1/2」「2/2」のように表示される
- [ ] 回数がすべて終わる（例：2/2になる）までは、パターンを選んだときにチェックが付いた状態で表示される
- [ ] 一括完了すると、その家事は1回分だけ完了になり、回数が1つ増える
- [ ] 回数がすべて終わったときに、線が引かれてグレーになる
- [ ] 完了した家事には線が引かれてグレーになる。相手の画面には、読み込み直したときに反映される
- [ ] 完了した家事は、家事の一覧の一番下に移動する
- [ ] 完了した家事には、完了した人のアイコンが表示される
- [ ] パターンに入っていない家事でも、今日1つずつ（各種選択で）完了したものは、ホーム画面の家事一覧の一番下に、グレーで表示される
- [ ] パターンに入っていない家事を1日に複数回完了したときは、完了した回数だけ行を並べて表示する。それぞれの行に、完了した人のアイコンが出る（1行にまとめて回数を出すより、作る負担が少ないため）
- [ ] 朝5時になると、メイン画面の線とグレーが消え、回数も「0/2」に戻る
- [ ] 朝5時を過ぎても、選んでいるパターンはそのまま残り、そのパターンの家事が全部チェックされた状態で表示される
- [ ] 前の日の完了記録とポイントは、朝5時を過ぎても消えずに残る

## 機能7：完了画面【高】

**ユーザーストーリー**  
同居人として、家事を完了したときに「完了！」の画面を見たい。
なぜなら、達成感が得られるから。また、間違えて完了にしたときに、その場で取り消せるから。

**受け入れ条件**
- [ ] 家事を完了すると（一括・1つずつのどちらでも）、完了画面が表示される
- [ ] 完了画面の取り消しボタンを押すと、完了が取り消され、ポイントも戻る
- [ ] 取り消すと、完了画面が閉じて、「取り消しました」というお知らせが数秒だけ表示される
- [ ] 一括完了の後に取り消すと、そのとき一括完了した家事がすべて取り消される

---

## 機能8：ご褒美システム【高】

**ユーザーストーリー**  
同居人として、家事をやるとポイントが貯まるようにしたい。
なぜなら、家事のモチベーションを保ち、お互いをねぎらえるから。二人にとってのゲーム感覚は「ポイントが貯まっていくこと」なので、一段落では、貯まるところまでを作る。

**受け入れ条件**
- [ ] 家事を完了すると、その家事のポイントが貯まる
- [ ] 自分の持っているポイントが、ホーム画面の上に、いつも表示される
- [ ] 自分が今日取ったポイントが、ホーム画面に表示される
- [ ] ご褒美の画面では、自分と相手の持っているポイントが見られる
- [ ] ご褒美の画面では、ポイントを使う機能は「準備中」と表示する

**一段落の後に作るもの【低】**
- [ ] ポイントとお金の換算を、二人のどちらでも設定・編集できる。「〇pt＝1円」の〇に、1〜999の数字を入れる（0は入れられない）
- [ ] 換算を入力すると、今の所持ポイントが何円になるかの例が、その場で表示される
- [ ] 換算した金額の小数は、切り捨てる
- [ ] ご褒美の画面で、自分の持っているポイントを換算した金額が表示される
- [ ] 使うポイントをバーで指定して、ポイントを使える。バーは、自分の持っているポイントまでしか動かせない
- [ ] ご褒美の画面の背景に、自分（そのスマホで選んでいるプロフィール）のポイントに合わせて星が積もっていく。100ptで星1つ、画面の下から上へ積もり、300こ（30,000pt）で画面がいっぱいになる。星は点滅させない（ポイントが貯まっていく様子を目で見られるようにして、モチベーションにつなげるため）

**使う機能を後回しにした理由**
規模を抑えるため。モチベーションの中心は「貯まっていくこと」なので、貯まる部分を残せば、目的は保てる。一段落の時点では、ポイントの使い道は、アプリの外で二人で決める（ポイントの譲渡もアプリの外に任せている）。

**補足**
貯まったポイント分の金額で、欲しいものを同居人に買ってもらう使い方を想定している。贈る側にとっても、日々の家事への感謝を伝える機会になる。

## 機能9：ご褒美の使用履歴【低】

**ユーザーストーリー**  
同居人として、ご褒美にポイントを使った記録を、あとから確認したい。
なぜなら、ポイントを使ったボタンを押したかどうか、分からなくなることがあるから。今のアプリには、課金版にもこの履歴が無い。

**受け入れ条件**
- [ ] ポイントを使った記録（日付、使った人、使ったポイント）を一覧で見られる
- [ ] 間違えて使った記録を削除すると、ポイントが戻る

**優先度を低くした理由**
今のアプリにも、ご褒美の使用履歴は無い。そのため、一段落の時点で無くても、今より不便にはならない。一段落の時点では、ポイントを使い間違えたときは、二人で話して対応する。

---

## 機能10：家事の完了履歴【低】

**ユーザーストーリー**  
同居人として、家事を完了した記録を、あとからさかのぼって確認したい。
なぜなら、あとで間違いに気づいたときに取り消したいから。

**受け入れ条件**
- [ ] 家事の完了記録を、日付付きの一覧で見られる
- [ ] 完了記録を削除すると、ポイントも戻る

**優先度を低くした理由**
完了画面でも取り消しができるため、一段落の時点では履歴が無くても困らない。完了画面を閉じた後に気づいた間違いは、一段落の時点では直せないと割り切った。履歴の利点は、完了画面を閉じた後でもさかのぼれること。

## やらないことリスト

- **時間の記録**：細かく記録しても不便は解消されず、タップ数が増える原因になるため
- **今日のやることリスト**：日によって変わっても、ある程度の型は決まっているので、パターンだけで不便がないため
- **カレンダー表示**：シンプルにしたいため
- **繰り返し通知**：毎日のリストが無く、夜にまとめて記録する人がいる前提のため
- **3人以上での利用**：同居している二人での利用を想定しているため。プロフィールは2つまで
- **権限の制限**：記録の編集やポイントの使用は、二人の信頼関係に任せるため
- **ポイントの譲渡**：ポイントの使い道は、アプリの外で二人の判断に任せるため

## メモ（実装しない。アイデアのみ）

- 定期メンテの記録、アラート、繰り返し機能（通知はメールではなく、アプリの通知で受け取りたい。スマホのブラウザで使うアプリでも Web Push で通知できるが、iPhone では PWA としてホーム画面に追加している必要がある）
- 日付が切り替わる時刻（今は朝5時で固定）を、設定で変えられるようにする
- 利用規約とプライバシーポリシー（アカウント作成のときに同意してもらう）。文章を書く必要があるため後回し
- ホーム画面でグレーになった家事のチェックを外すだけで、確認なしで完了を取り消せるようにする
- アカウントのアイコンを、用意した中から選べるようにする。さらに後で、写真や画像のアップロードでも決められるようにする（画像を保存する仕組みが新しく必要になり負担が大きいため）。一段落では、ニックネームの頭文字と、プロフィールを作った順で決まる色で表示する
- ポイント表示を押すと、今日二人がそれぞれ何ポイント取ったかを見られる
- パターンの組み合わせ（「平日」に「洗濯」を足して選ぶ）や、パターンのコピー。パターンが増えて、家事が変わったときに直すのが面倒になったら検討する
- 最近使った家事の表示（パターンは除く）
- ロック画面やホーム画面のウィジェットから、家事をすぐに完了する（ホーム画面用に設定でき、パターンも表示できる）。タップ数を一番減らせる案かもしれない
- いつもより大変だったときは、ポイントを＋−で調整できる（調整しなくても完了できる）。あったら助かるが、企画の困りごとに直接つながらないため、今回の仕様には入れない
- 共同：二人でやった家事を完了して、ポイントを半分ずつ分ける。＋−の調整と同じく、困りごとに直接つながらないため後回し
- ＋−の調整や共同を作るときは、各種選択画面で家事の行を押すと、大変さや共同を選ぶ画面が開き、そこで完了する形にする
- 各種選択画面のシートを、下に引っぱって閉じる。指の動きを読み取る仕組みが新しく必要で、シートの中の一覧のスクロールとぶつからないようにするのも難しいため後回し。一段落では×ボタンで閉じる
- 家事の並べかえ（「＝」をつかんで動かす）。指でつかんで動かす操作はカリキュラムで扱っていない新しい仕組みのため後回し。一段落では名前の順に並べ、「＝」も表示しない

## 確認時（2026-10-29）から変わったところ

**講師の指摘で変えたこと**
- パターンの作成・編集・削除を、パターンで一括完了する機能から分けて、別の機能（機能4）にした。そのため、機能5以降の番号が1つずつずれた

**規模を抑えるために変えたこと**
- グループを作って合言葉で参加する形をやめて、家で1つのアカウントを二人で共有し、二人のプロフィールを選ぶ形にした（機能1・2）
- 相手の画面への反映は、画面を読み込み直したときにした
- 日付を選んで記録するのを後回しにした（一段落では、いつも今日の日付）
- ご褒美の使用履歴の優先度を、高から低にした（機能9）
- 同じ名前の家事のチェックを後回しにした（機能3）
- アイコンは選ばずに、ニックネームの頭文字と決まった色で表示するようにした
- メモに移したもの：共同、家事の並べかえ、シートを下に引っぱって閉じる操作
- 家事カテゴリを後回しにして、代わりに各種選択画面に検索を付けた（機能3・5）。各種選択画面は、ホーム画面の右下の虫眼鏡のボタンから開く
- ポイントは「貯まる」までにして、「使う」（換算・バー）を後回しにした（機能8）。講師への回答で答えた一段落（〜ポイントが入る。ポイントを使用できる。まで）から、「ポイントを使用できる」を外したことになる

**③画面を作る中で決めたこと・変わったこと**
- 1日に複数回やる家事の回数は、数字で決めるのをやめて、同じ家事をパターンに2回入れる形にした（機能4）
- 各種選択は、家事を名前の順に並べ、前回完了した日を出し、家事の行を押すとそのまま完了にした（機能5）
- 家事のポイントは、バー（10〜200）か直接入力（0〜999）で決めるようにした（機能3）
- ポイントの表示は、すべての画面の上からホーム画面だけにし、今日取ったポイントも出すようにした（機能8）
- 換算は「〇pt＝1円」の〇だけを入力し、例をその場で出し、小数は切り捨てるようにした（機能8。一段落の後に作る）
- 完了を取り消したときに「取り消しました」のお知らせを出すようにした（機能7）
- パターンに入っていない家事でも、今日完了したものはホーム画面に出すようにした（機能6）
- ポイントの数字を、大きさで4色に色分けするようにした（機能3）
- 家事を追加するときに、画面を閉じずに続けて追加できるようにした（機能3）。まとめて入力する形や、よくある家事から選ぶ形も考えたが、作る負担が軽いこの形にした
